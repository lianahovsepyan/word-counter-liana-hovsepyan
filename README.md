# Word Counter App

A simple single-page JavaScript application built for TUMO Labs. It analyzes text in real time and displays counts for letters, words, and sentences, along with a custom background generator.

## Features
- Real-time letter count (excluding spaces).
- Word and sentence count metrics.
- Random background color generator button (Bonus).

## Tech Stack
- HTML5, CSS3, JavaScript (DOM Manipulation, ES6)
- Git & GitHub
